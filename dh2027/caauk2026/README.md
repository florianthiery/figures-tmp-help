# caauk2026: figures of the CAA-UK 2026 talk (Glasgow)

`figs.py` builds the diagrams of the talk (ecosystem, stone, benchmarks, OSM static, TEI layers) in the same style as `../figures/figures.py`.

## Run (Windows cmd, one line)

```
cd /d C:\git\wikibase-static-help\dh2027\caauk2026 && pip install resvg_py pillow && python figs.py
```

Output: `out/*.svg` and `out/*.png`. Fonts (Fira Sans, SIL Open Font License) are included.
